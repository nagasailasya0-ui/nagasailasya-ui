## 🧬 05 | Interactive DNA Analysis

One of the ideas behind LASYA.BIO is making bioinformatics understandable through interactive experiments.

For a DNA sequence containing the bases `A`, `T`, `C`, and `G`, a sequence analyzer can explore:

| Analysis | Scientific purpose |
|---|---|
| Sequence length | Counts the number of nucleotides |
| GC content | Calculates the percentage of G and C bases |
| Complementary strand | Applies DNA base-pairing rules |
| RNA transcription | Converts DNA sequence information into RNA |
| Translation | Maps coding RNA codons to amino acids |

**Example**

```python
from Bio.Seq import Seq

dna = Seq("ATGCGATCGTAAGCTAGCTA")

print("DNA:", dna)
print("Length:", len(dna))
print("GC Content:", round(
    100 * (dna.count("G") + dna.count("C")) / len(dna), 2
), "%")
print("Complement:", dna.complement())
print("RNA:", dna.transcribe())
print("Protein:", dna.translate())
```

This example demonstrates basic sequence operations using Biopython. Biological interpretation depends on sequence quality, reading frame, and whether the sequence represents a valid coding region.
